# Outreach Targets

## Best First Posts

1. Reddit `r/PSP`: `https://www.reddit.com/r/PSP/`
2. Reddit `r/psphacks`: `https://www.reddit.com/r/psphacks/`
3. Wololo PSP coverage: `https://wololo.net/`
4. PSP Place blog/contact: `https://psp.place/blog/`
5. Retro Handhelds: `https://retrohandhelds.gg/`

## Why These Fit

- `r/PSP`: Largest obvious audience for people actively using or restoring PSP hardware
- `r/psphacks`: Better fit for homebrew and modding-minded users
- Wololo: Still publishing PSP-related news in 2026 and has an audience that tracks releases
- PSP Place: Smaller, but directly aligned with PSP guides and ongoing homebrew
- Retro Handhelds: Good angle for "repurpose old hardware" storytelling

## Contact Notes

- PSP Place currently lists `admin@storm-services.tech` on its blog page for feedback, questions, or suggestions.
- Wololo appears to still publish PSP-related news items, so it is worth pitching as a short release note with a GitHub link and one screenshot.

## Suggested Order

1. Push README and repo polish live
2. Make sure the GitHub Releases page is the link destination
3. Post to `r/PSP`
4. Post a slightly more technical version to `r/psphacks`
5. Send a short pitch to Wololo and PSP Place
6. Repost the best short demo clip on social platforms

## Pitch Angle By Channel

### Reddit `r/PSP`

Lead with the user outcome:

"I built an EPUB reader for the PSP, so old hardware can work as a dedicated ebook reader."

### Reddit `r/psphacks`

Lead with homebrew plus device constraints:

"A PSP homebrew EPUB reader with TATE mode, persistent progress, and battery-saving CPU scaling."

### Wololo

Lead with release value and scene relevance:

"Open-source PSP homebrew release: an EPUB reader focused on real reading, not just a proof of concept."

### PSP Place

Lead with usefulness for real owners:

"A new PSP homebrew app that turns the handheld into a practical EPUB reader with saved progress and theme controls."

### Retro Handhelds

Lead with the repurposing story:

"Giving old gaming hardware a second life as an ebook reader."

## Assets To Prepare Before Outreach

- 1 clean device photo
- 1 short scrolling video
- 1 screenshot of library view
- 1 screenshot of rotated TATE mode
- GitHub release link
- 2-sentence install summary
