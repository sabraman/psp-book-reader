PSP-BookReader Release Package

Install:

1. Copy the included `PSP-BookReader` folder into `PSP/GAME/` on your Memory Stick.
2. Keep the `fonts/` directory next to `EBOOT.PBP`.
3. Put your `.epub` files where the app can index them.
4. Launch PSP-BookReader from the PSP Game menu.

Included:

- `PSP-BookReader/EBOOT.PBP`
- `PSP-BookReader/fonts/Inter-Regular.ttf`
- `PSP-BookReader/fonts/DroidSansFallback.ttf`
