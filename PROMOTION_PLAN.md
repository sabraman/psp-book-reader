# PSP-BookReader Promotion Plan

## Positioning

Primary hook:

Turn an old PSP into a dedicated EPUB reader.

Supporting angles:

- Real homebrew for original Sony PSP hardware
- Built for long reading sessions, not just novelty
- Careful optimization for battery life and low-memory hardware
- Supports Latin, Cyrillic, and CJK-friendly reading workflows

## Best Audiences

1. PSP homebrew users
2. Retro handheld communities
3. Ebook and EPUB enthusiasts
4. Developers who enjoy low-level optimization
5. People interested in repurposing aging hardware

## Best Channels

Priority 1:

- GitHub repository polish
- GitHub Releases
- Reddit: `r/PSP`, `r/PSPhacks`, `r/homebrew`, `r/eretrohandhelds`, `r/epub`
- Relevant Discord servers and forums for PSP homebrew

Priority 2:

- Hacker News: only if the post leans into systems constraints and optimization
- X / Mastodon / Bluesky
- YouTube short demo or GIF thread

## Message Strategy

Lead with outcome, then proof.

Good:

"I built an EPUB reader for the PSP with TATE mode, cover art, persistent progress, and battery-saving CPU scaling."

Less effective:

"Here is my C++/SDL2 project with various rendering and caching optimizations."

## Launch Checklist

Before posting:

- Confirm the current public version number is consistent across `README.md`, release notes, and packaged artifacts
- Add 3 to 5 screenshots or short device clips
- Publish a GitHub Release with a short install section
- Add a short "Why this exists" paragraph to the repo
- Verify installation steps on real hardware or emulator

Launch day:

1. Publish the GitHub Release
2. Post a short demo clip
3. Share a tailored post to Reddit communities
4. Share a technical post for developer audiences
5. Respond to comments quickly for the first 24 hours

Week after launch:

1. Post an update with battery-life wins or new format support
2. Package feedback into a small roadmap
3. Invite testers to try unusual EPUBs and language sets

## Content Ideas

- "I turned my PSP into an ebook reader"
- "A practical homebrew app for PSP, not just a demo"
- "Battery-aware EPUB reading on 32MB hardware"
- "What it took to render EPUBs smoothly on a PSP"
- "Giving old gaming hardware a quiet second life"

## What To Measure

- GitHub stars and watchers
- Release downloads
- Traffic sources to the repo
- Number of comments and reposts per channel
- Number of bug reports from first-time testers

## Immediate Next Moves

1. Make the repo landing page sharper
2. Prepare release copy and community-specific launch posts
3. Create a simple press kit folder with screenshots and a one-paragraph description
4. Publish through GitHub and social/community channels
